# Riwaq 2.0 Design System

## Palette
- Graphite: `#111411` — app canvas and header
- Panel: `#1A1F1A` — primary surfaces
- Raised panel: `#222922` — secondary surfaces
- Paper: `#F2EFE5` — primary text / light surfaces
- Acid lime: `#D7FF4F` — primary action and progress
- Cobalt: `#315DFF` — secondary emphasis and focus
- Muted: `#9CA59A` — secondary text
- Line: `#343D32` — separators and borders

## Typography
- IBM Plex Sans Arabic: interface and controls
- Amiri Quran: Quran text only

## Principles
- Editorial hierarchy, asymmetric hero composition, high-contrast information blocks.
- Square/short-radius geometry; avoid generic pill-heavy UI.
- Motion is subtle and respects `prefers-reduced-motion`.
- Navigation is thumb-friendly and fixed to the bottom on mobile.
- All application copy remains Arabic and RTL.

## Brand mark
Abstract architectural arch enclosing an open book. Lime arch, ivory book, cobalt focal point. No emoji as brand assets.
